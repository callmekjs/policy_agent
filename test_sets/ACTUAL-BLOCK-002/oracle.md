# ACTUAL-BLOCK-002 쉬운 정답표

이 자료는 실제 공개자료지만 현재 1차 프로그램이 처리하기에는 너무 복잡하다.

- 박정 의원 원안 2204668은 `대안반영폐기`다. 원안이 그대로 통과된 것이 아니다.
- 실제 본회의 통과 대상은 위원회 대안 2216789다.
- 이 대안에는 원안 11건이 연결돼 있고 변경 조문도 6개다.
- 현재 1차 범위는 원안 1건과 최종 대안 1건, 변경 조문 1~3개까지만 허용한다.

따라서 프로그램은 초안을 만들면 안 된다. “현재 지원 범위를 넘는 복잡한 대안입니다”라고 쉽게 설명하고, `NEEDS_INPUT`에서 새 작업을 안내해야 한다. 특히 “박정 의원 원안이 그대로 원안가결됐다”라고 쓰면 중대한 실패다.
