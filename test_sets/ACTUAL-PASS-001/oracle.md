# ACTUAL-PASS-001 쉬운 정답표

이 사례는 현재 1차 범위에 맞는 정상 문제다.

- 법률 1개, 의안 1개, 변경 조문 1개다.
- 공식 자료 안에서 본회의 `원안가결`을 확인할 수 있다.
- 같은 의안의 소관위와 법사위 처리결과도 모두 `원안가결`이라 중간 내용 변경이 없음을 확인할 수 있다.
- 현행 조문과 최종 변경 문구가 모두 있다.
- 부칙은 “공포한 날부터 시행”이지만, 기준일에는 아직 공포 전이다.

따라서 프로그램은 DRAFT 초안을 만들어 사용자 검토 화면에 보여줘야 한다. 다만 “법이 이미 개정됐다”, “공포됐다”, “현재 시행 중이다”라고 쓰면 실패다. 공식 자료에 없는 표결 수나 의원 인용문도 만들면 안 된다.

발의안·심사이력·표결 결과는 서로 다른 문서이므로 문서 ID와 해시는 서로 같지 않아도 된다. 각 파일의 해시는 자기 manifest 항목과 일치해야 하며, 세 자료의 의안번호와 소관위·법사위·본회의 처리결과를 코드가 따로 대조해야 한다.
