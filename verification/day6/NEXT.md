```

start-local.cmd        ← 가짜 AI. 인터넷으로 안 나가고 0원.
```

## 오늘 고친 것 (8자리, 전부 시험 포함)

전부 **AI가 형식을 완벽히 지켜도 통째로 버려지던** 종류였다.

| 자리 | 무엇 |
|---|---|
| 형식 ↔ 계약 | `procedure_stage`/`disposition`이 자유 글자였다 → 코드 목록 |
| 형식 ↔ 계약 | 형식은 알맹이, 계약은 봉투 → 보낼 때 봉투를 씌운다 |
| strict 모드 | `const`·모양 없는 칸·`items` 없는 배열 → 좁히는 쪽으로만 옮김 |
| 지시문 | Agent 셋이 공통 한 문단만 받았다 → 각자 지시문 |
| `draft_gate` | `고전` 오탐 (`…방지하고 전문예술…`) → 진짜 인용만 잡게 좁힘 |
| `draft_vocabulary` | `의안번호` 추가 (`의안`·`번호`는 있었다) |
| 화면 정직성 | 진짜인데 "가짜 AI, 0원"이라고 적혀 있었다 |
| 화면 흐름 | `.env` 안 읽음 / 역할 초기화 / 발표 주체 안 물음 |

## 안 고친 것 — 다음에 정해야 한다

### 1. 주석님 PDF로는 통과가 안 된다 ⚠ 제일 중요

```
발의안 원문 PDF 인쇄:  의안번호 7285      ← 눈으로 확인함
의안정보시스템:         제2207285호
규칙(§2.16.2 조건 2):   세 자료의 의안번호가 같아야 한다
```

`220`은 22대 국회를 뜻하는 접두어로 **의안정보시스템이 붙이는 것**이고
발의안 원문에는 인쇄되지 않는다. 즉 실제 국회 PDF를 그대로 넣으면
**절대** 통과하지 못한다.

안전 규칙이라 임의로 풀지 않았다. 정할 것:
- (가) 짧은 번호(`7285`)가 긴 번호(`2207285`)의 끝과 같으면 같은 의안으로 볼까
- (나) 사람에게 "이 셋이 같은 의안이 맞습니까"라고 묻고 넘어갈까
- (다) 그대로 두고 의안정보시스템 화면을 함께 넣게 안내할까

README §2.16.2를 건드리는 일이라 Codex와 역할 분담도 함께 정해야 한다.

### 2. 글이 뻣뻣하다 — 근본 원인은 어미

초안이 쓸 수 있는 낱말은 **원장 값 + 근거 문구 + 안전낱말 158개**뿐이고,
낱말을 자르거나 어미를 바꿀 수 없다.

```
자료에 있는 말:   …것을 구분하고 있는데
AI가 쓰고 싶은 말: …을 구분한다
프로그램:         '구분하고'는 통째로 한 낱말이다. '구분'만 잘라 쓸 수 없다 → 막음
```

낱말을 자르지 못하게 한 것은 옳다(`조계원`에서 `조계`가 나오면 안 되니까).
대가로 AI가 자료 문구를 거의 그대로 붙이는 쪽으로 도망간다. 그래서
`실무 현장에서 혼선이 발생하고 있음.` 같은 문장이 그대로 실린다.

정할 것: 어간 + 정해진 어미 조합을 허용할까, 아니면 지금 문체를 받아들일까.

### 3. `다는`/`라는` 오탐

문단에 `의원`이 있고 어느 문장에든 `다는`·`라는`이 있으면 인용으로 본다.
관형형(`있다는 사실`)까지 걸린다. `고전`과 같은 종류의 오탐이고, 지금은
지시문으로 우회하고 있다.

### 4. 같은 종류 사실 2건 = 무조건 충돌

표결 수·날짜에는 맞지만 설명 문장(`PROPOSAL_REASON`)에는 맞지 않는다.
지금은 "각각 한 건만" 뽑으라고 지시문으로 막고 있다.
