## 12차 지적을 고쳤다 (2026-08-26)

12차가 뚫은 `H1`을 고쳤다. 데모를 먼저 만들자는 이야기가 있었으나, 순서를
바로잡아 **고치고 나서 검토를 받는다.**

### 무엇이 뚫렸었나

효력 낱말이 **원장 값 안에** 있으면 넘어가는데, 값 **뒤에 붙는 어미를 보지
않았다.** 값이 효력 어간으로 끝나면 그 뒤에 무엇이 붙어도 지나갔다.

```
발표 주체가 "개정"일 때
초안:  이 법률은 개정되었다.   ← 그대로 나갔음 (draft_version=1, 차단 0건)
```

### 어떻게 고쳤나

값 안에 있기만 하면 되던 것을, **값의 한가운데에 있을 때만** 넘어가게 했다.

| 값 | 어간 자리 | 판정 |
|---|---|---|
| `문화예술진흥법 일부개정법률안` | 한가운데 | 통과 — 앞뒤가 값 자신의 글자로 막혀 있다 |
| `…법률 전부개정` | 끝 | **막힘** — 뒤에 `되었다`를 붙일 수 있다 |
| `개정` (발표 주체) | 값 전체 | **막힘** |

검사하는 글은 공백을 지운 뒤라 낱말 경계가 없다. 그래서 낱말 경계 대신
**값 안에서의 자리**로 판정한다.

### 확인한 것

- 12차가 뚫은 4종 전부 막힘
- 정상 초안은 그대로 나옴 (`draft_version=1`)
- 시험 437개 통과
- 변조 시험 — 값 가장자리도 봐주게 되돌리면 시험이 죽는다
