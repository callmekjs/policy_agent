## 공격 시험

## 스스로 찾은 `남은 일`

차단 기준에는 없다. 심각도와 갈 일차를 적는다.

1. **핵심 요약 개수 위반의 안내가 불친절하다** (중 / 6일차)
   2개 미만이면 schema 층에서 먼저 막혀 `DRAFT_SCHEMA_INVALID` 기술 오류로 보인다.
   초안은 확실히 0건이라 안전하지만, 사용자는 무엇이 잘못됐는지 알 수 없다.
   진짜 AI로 바꾸고 형식 재시도를 붙일 때 함께 다룬다.

2. **가짜 추출기가 다른 법률 이름을 사실로 뽑는다** (하 / 6일차)
   `「기부금품의 모집 및 사용에 관한 법률」`은 인용된 다른 법인데 `BILL_TITLE`로
   올라온다. 초안 제목에는 쓰이지 않지만 화면 사실 목록에 나온다.
   합격선의 "가짜 추출기 품질" 제외 항목에 해당한다.

3. **초안 문장이 어색하다** (하 / 12일차)
   `은(는)`, `이(가)` 같은 조사 처리를 하지 않는다. 글쓰기 규칙 일차에서 다룬다.

4. **화면을 새로 고치면 진행 중인 작업을 잃는다** (중 / 5일차)
   작업 ID가 React 상태에만 있어 주소로 되돌아갈 수 없다. 서버에는 2시간 남아
   있는데 화면에서 다시 열 길이 없다.

5. **확인에 "예"를 누르면 새 작업이 만들어진다** (하 / 5일차)
   같은 작업 안에서 답하는 것이 아니라 지우고 다시 만든다. 안전하지만 작업 ID가
   바뀐다. 5일차의 답변 처리 API가 생기면 같은 작업 안에서 답하도록 바꾼다.
